# Angadi Food Truck Website Template

A modern, mobile-friendly single-page website for an Indian street food business. This template is built with HTML, CSS, and minimal JavaScript so it is easy to customize and resell.

## Included Files

- `index.html` — main website content and structure
- `styles.css` — responsive styling and design
- `script.js` — mobile navigation and contact form behavior

## How to Customize

1. Change the brand name in `index.html` at the top logo and page title.
2. Replace the hero and section images by updating the `src` values in `index.html`.
3. Add your menu screenshot files to the project folder as `menu1.png`, `menu2.png`, `menu3.png`, and `menu4.png`.
4. Open `index.html` directly in a browser to preview the site.
5. Adjust colors in `styles.css` under the `:root` variables.

## Simple editing without installing software

If the owner does not want to install anything, use a host or repository that lets them edit files in a browser and publish automatically:

- GitHub Pages is the easiest option. Upload the project to a GitHub repository, invite the owner as a collaborator, then they can:
  1. open `index.html` or `styles.css` in the GitHub web editor
  2. make changes directly in the browser
  3. commit the file
  4. GitHub Pages will publish the site automatically.
- Vercel or Netlify also work if the site is connected to a GitHub repo. When the owner updates files in the repo, the host rebuilds and publishes the site.
- Some hosting providers have a web file manager where the owner can edit HTML, CSS, and image files from a browser.

This is the closest workflow to Google Sites: open a web page, edit content, save, and publish without installing desktop software.

## Deploying the site

1. Choose a host such as GitHub Pages, Vercel, or Netlify.
2. Upload the project folder or connect a Git repository.
3. Set the root directory to the folder containing `index.html`, `styles.css`, and `script.js`.
4. Publish the site.

Most static hosts will provide a free website address automatically.

## Connect a free domain

1. Visit https://www.freenom.com and create an account.
2. Search for a free domain like `.tk`, `.ml`, `.ga`, `.cf`, or `.gq`.
3. Register the domain and open the domain management screen.
4. Point the domain to your host using DNS settings.
5. Wait a few minutes for DNS to propagate.

## Notes for Resale

- Keep the menu structure flexible: categories are in `script.js` and can be easily updated.
- Provide clients with the simple editing guide in the menu section.
- Send the folder with `index.html`, `styles.css`, `script.js`, and `menu1.png` through `menu4.png`.
- Use the placeholder images and copy as sample content, then replace them with the client’s own branding.
